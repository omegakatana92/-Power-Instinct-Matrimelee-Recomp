# Power Instinct Matrimelee Recomp

Power Instinct Matrimelee Recomp is a native static recompilation of the 2003 Neo Geo fighter Matrimelee, also known as Shin Gouketsuji Ichizoku Toukon, built with sp00nznet's NeoGeoRecomp toolkit. Rather than wrapping a conventional emulator, it translates the cartridge's Motorola 68000 program ahead of time into readable C and runs that code directly against an MVS board model. The real system ROM still boots, so BIOS, coin handling and cartridge hand-over behave as on hardware.

Deliverables are a Windows x64 executable and a Linux x86_64 AppImage for Steam Deck. Both include SDL2 video, audio and gamepad support. The AppImage starts fullscreen at 1280x800, pillarboxing the 4:3 picture. A build-time tool prepares the retail encrypted set, handling the K2K2 P-ROM permutation, NEO-CMC 7050 graphics and embedded fixed layer, CMC50 M1 sound program, and NEO-PCM2 mode-1 V-ROM scramble. Prepared data matches independent Darksoft reference hashes.

A 19,000-frame session is 100.00 percent native: 365 million native instructions, 114 interpreted and no uncovered entry points. Musashi verification reports zero mismatches, and native and interpreter frames are byte-identical. Tests reach boot, attract, HOW TO PLAY, select and a full match with correct graphics, HUD and audio. The Z80 driver and YM2610 run through ymfm; output resamples 55,555 Hz to the device rate and recovers underruns without dropping samples. Remaining quiet windows are game content, not driver stalls.

The repository contains the game host, ROM layout, decryption tool, tests, packaging and documentation, plus the vendored toolkit. Original code is licensed under PolyForm Noncommercial 1.0.0. NeoGeoRecomp, Musashi, superzazu/z80, ymfm, SDL2 and the MAME-derived decryption code retain their MIT, BSD-3-Clause and zlib licenses. No SNK ROMs, BIOS files, recompiled game code, entry lists or gameplay artwork are distributed. Users must supply their own legally obtained MAME matrim and neogeo sets. Windows users run the included Prepare-ROMs script; Linux users place the unzipped files beside the AppImage or use --prepare-roms. Physical Steam Deck, Steam Input, gamepads and audio quality remain untested. The project shows a practical path from a protected Neo Geo cartridge to maintainable native builds while preserving upstream attribution and excluding copyrighted data.
